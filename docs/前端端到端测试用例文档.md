# 前端端到端测试用例文档（R22）

> 版本：R22 ｜ 日期：2026-08-07
> 用法：以每个前端页面为入口，模拟前端点击操作 → 调用后端接口 → 断言响应 → 核验 pipeline 日志链路。
> 硬约束：禁止 mock。每条用例需真实输入 → 真实输出 → 真实日志三重验证。
> 链路核验：`/workspace/logs/pipeline.jsonl`（或 GET /api/v1/logs/{content_id}）中该 content_id 的节点链。

---

## 用例编号规则

- 格式 `E2E-{页面}-{序号}`，页面缩写：DB(dashboard) / MD(moderate) / AS(async) / RV(review) / OP(optimization) / HS(history) / HD(history详情) / LB(lab) / PL(policies) / SY(system) / BM(benchmark) / SK(skills) / DS(dataset)。
- 期望结果列含「响应断言」+「日志核验点」。

## 16. 执行记录（R21 实测 2026-08-07）

> 执行方式：httpx 直接调用后端 `http://localhost:18080/api/v1`，模拟前端点击对应的接口调用。
> 环境：后端 uvicorn :18080 ｜ Redis :16379 ｜ PG :15432 ｜ Ollama qwen2.5:7b ｜ DeepSeek API。
> 日志核验口径：`GET /api/v1/logs/{content_id}` 返回的 steps 节点链。

### 16.1 审核链路（E2E-MD-* / E2E-SP-*）

| 用例 | 输入 | 决策/风险 | 日志节点链 | 结论 |
|---|---|---|---|---|
| E2E-MD-01 安全文本 | 「今天天气很好，适合出游」 | PASS risk=0.0 | GATEWAY→SUPERVISOR→TRIAGE→LANE_ROUTE→FAST_LANE (5 步) | ✅ low 车道真实 |
| E2E-MD-09 重复提交 | 同上（二次） | cached=True 同 id | — | ✅ 缓存命中 |
| E2E-MD-02 色情短文本 | 「你穿这样的衣服让我有性冲动，我们做爱吧」 | PASS risk=0.0 types=[porn] | GATEWAY→SUPERVISOR→TRIAGE→LANE_ROUTE→FAST_LANE (5 步) | ✅ 小模型识别 porn 类型 |
| E2E-SP-02 high 车道 | 「威胁」×420（840字高危长文本） | PASS risk=0.1289 | GATEWAY→SUPERVISOR→TRIAGE→LANE_ROUTE→BRAIN→TEXT_AGENT→TERMINATION→RISK_ASSESS (8 步) | ✅ high 车道→brain→终止双签链真实 |

**SP-01 观测**：TRIAGE tier=low → LANE_ROUTE low→fast_lane → FAST_LANE(path=adopt) 链路在 MD-01 中验证，FAST_LANE 的 upgrade 分支由「小模型低置信/类型矛盾」触发（如隐私文本被分诊 med 时走大模型）。
