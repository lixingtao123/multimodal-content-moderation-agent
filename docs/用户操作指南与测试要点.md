# 内容风控智能治理系统 — 用户操作指南与测试要点

> 本文档教你使用这个系统的每一个页面功能。不涉及复杂技术原理，只告诉你：怎么操作、会发生什么、怎么看效果。

---

## 一、首页 Dashboard — 数据看板

### 页面长什么样

打开 http://localhost:13000/dashboard，从上到下依次是：

1. 顶部 4 个统计卡片：审核总数、通过率、平均风险分、平均处理耗时
2. 饼图区：决策分布（PASS/REVIEW/REJECT）+ 违规类型分布
3. 柱状图：内容类型分布（text/image/audio/video）
4. 折线图：近 7 天审核趋势
5. Token 用量卡片：LLM 调用次数、预估 Token、预估花费
6. 面积图：近期处理耗时趋势
7. 健康状态：PostgreSQL/Redis/ChromaDB/FunASR 运行状态
8. 最近日志列表

### 背后发生了什么

```
页面加载
  → 并行发 4 个 API 请求:
    GET /api/v1/admin/statistics       → 基础统计
    GET /api/v1/admin/stats/overview   → 7天趋势 + 违规分布
    GET /api/v1/logs/recent/all?limit=20 → 最近日志
    GET /health                        → 服务健康
  → 每 15 秒自动刷新
```

### 如何验证

- [ ] 4 个统计卡片有数据
- [ ] 饼图/柱状图/折线图正常渲染
- [ ] Token 卡片显示用量估算
- [ ] 健康状态全部绿色"正常"
- [ ] 最近日志列表不为空

## 二、内容审核面板 — 提交审核

### 页面长什么样

5 个 Tab 切换：
- **文本审核**：文本输入框 + 提交按钮
- **图片审核**：拖拽上传区 + 文件预览
- **音频审核**：拖拽上传区
- **视频审核**：拖拽上传区（最大 100MB）
- **多模态审核**：文本输入 + 多文件上传（PDF/Word/图片/音频）

右侧：审核结果面板（提交后显示）

### 你可以做什么

**① 文本审核**
- 在文本框输入内容，点"提交审核"
- 右侧面板实时展示审核结果

**② 图片审核**
- 拖拽或点击上传一张图片，点"提交审核"

**③ 音频审核**
- 拖拽或点击上传音频文件（mp3/wav/flac/m4a/aac/ogg），点"提交审核"

**④ 视频审核**
- 拖拽或点击上传视频文件（最大 100MB），点"提交审核"

**⑤ 多模态审核**
- 输入文本 + 选择文件（支持 PDF/DOCX/TXT/图片/音频）
- 系统自动调用 Planner 进行 5 阶段编排

### 结果面板怎么看

提交后右侧显示：

```
┌────────────────────────────┐
│     ○ 风险分 78%  ○        │  ← 圆环图，颜色表示风险等级
│                            │    绿色 <35%  黄色 35-70%  红色 >70%
│   决策: REJECT (红色标签)   │
│   违规: advertisement      │
│   处理: DELETE (HIGH)      │  ← 建议操作 + 优先级
│                            │
│   ▼ 推理详情 (可展开)      │
│   TextAgent:               │
│     violation=advertisement│
│     confidence=0.85        │
│     推理链:                 │
│       [关键词检测] 命中3个   │
│       [语义分析] 检测到引流  │
│       [RAG检索] 找到2个案例 │
│       [风险计算] → 0.72     │
└────────────────────────────┘
```

### 背后发生了什么（文本审核为例）

```
你输入"加我微信赚钱"回车
  → 前端发 POST /api/v1/moderate/text 到后端
  → Supervisor: 识别为 text 类型, 登记任务
  → Triage 分诊台 (ModelRouter 三层路由):
     低风险 → 快车道 (本地小模型, 秒级返回, 不调大模型)
     高风险 → 大脑仲裁 (4 类决策) → 标准链路
     中等   → TextAgent
  → TextAgent:
      1. AC 自动机扫敏感词 (~1ms)
      2. 黑灰产检测 (模式+对抗) (~1ms)
      3. RAG 检索历史案例 (~50ms)
      4. CoreMemory 召回高重要性案例
      5. DeepSeek 语义分析 (~800ms)
      6. Skill 知识注入 system prompt
      7. 综合评分 (关键词0.3 + 语义0.5 + 案例0.2)
  → 条件路由 (route_after_agent):
     违规 + 置信度<0.6/对抗 → ReAct 深挖
     否则 → RiskAgent
  → RiskAgent: 意见协商(加权投票) + 综合评估 → PASS/REVIEW/REJECT
  → 结果保存到 PostgreSQL + Redis + ChromaDB
  → 异步: AnnotationAgent 自动标注
```

### 多模态审核的完整流程

```
你上传 DOCX(含20张嵌入图) + PNG + WAV
  → Supervisor: 识别为 multi_modal
  → Triage 分诊台: 非文本 → 默认 med → 标准车道
  → Planner:
     Phase 1: FileAgent 解析 DOCX → 9,000字 + 20张嵌入图
     Phase 2: ImageAgent×21 ‖ AudioAgent×1 并行分析 (Semaphore 5)
     Phase 3: 图片判定按位置插回原文 + ASR转写 → 融合文本 → TextAgent 分段审核
              (OCR 段单独收集, 不拼入融合文本, 仅用于统计+跨模态关联)
     Phase 4: 跨模态关联 (图文矛盾/互证/OCR关联/音频关联)
     Phase 5: 输出结果 + 标记 _planner_processed
  → FileAgent/TextAgent: 检测到 _planner_processed → 跳过
  → RiskAgent (内嵌意见协商) → END
```

### 测试用例

| 输入 | 预期结果 | 说明 |
|------|---------|------|
| "今天天气真好" | PASS, 低风险 | 正常内容 |
| "加我微信赚钱带你飞" | advertisement, 中高风险 | 广告引流 |
| "你这个废物去死吧" | harassment, 高风险 | 辱骂内容 |
| 空文本 | error: empty text | 空内容处理 |
| 上传一张普通风景照 | PASS | 正常图片 |
| 上传一段语音 | ASR 转写完成→文本审核 | 语音审核 |
| 上传含嵌入图的 DOCX | Planner 提取所有图并分析 | 多模态编排 |

## 三、异步审核面板 — 批量任务

### 页面长什么样

- 左侧：任务提交区（文本 + 多文件拖拽）
- 右侧：任务列表 + 结果详情

### 你可以做什么

**① 提交异步任务**：输入文本 + 上传文件→点"提交任务"→状态显示 QUEUED

**② 查看任务进度**：任务列表每 3 秒自动刷新。状态变化：QUEUED → PROCESSING → COMPLETED/FAILED

**③ 查看结果**：点击 COMPLETED 的任务→展开结果详情

### 状态说明

| 状态 | 含义 | 颜色 |
|------|------|------|
| QUEUED | 排队等待处理 | 灰色 |
| PROCESSING | 正在处理中（有进度条） | 蓝色 |
| COMPLETED | 处理完成 | 绿色 |
| FAILED | 处理失败 | 红色 |
| AWAITING_HUMAN | 需要人工审核 | 橙色 |
| CANCELLED | 已取消 | 灰色 |

## 四、人工审核面板 — Human-in-the-Loop

### 这是什么

当 AI 对某条内容拿不准时（置信度低/Agent 意见不一致），会标记为需要人工审核。

### 你可以做什么

**① 查看待审核列表**：每 10 秒自动刷新

**② 进行人工标注**：点击"开始标注"→左侧看原始内容+AI判定→右侧填写：
- **决策**：PASS / REJECT / REVIEW
- **违规类型**：7 选 1（none/politics/porn/violence/false_info/harassment/advertisement）
- **置信度**：0-100% 滑块
- **理由**：填写判定依据
- **标签**：可添加自定义标签
- 点"提交标注"

**③ 实时对比**：表单下方显示 AI vs 人工对比

## 五、策略管理 — 敏感词与阈值

### 页面长什么样

2 个 Tab：
- **敏感词库**：关键词策略列表 + 新建表单
- **阈值配置**：Review/Reject 阈值 + 评分权重

### 你可以做什么

**① 管理敏感词**
- 查看已有敏感词策略（名称、级别、关键词列表）
- 新建策略：名称 + 级别（高/中/低）+ 关键词（逗号或换行分隔）
- 启用/禁用某个策略
- 删除策略（有确认弹窗）

**② 配置阈值**
- 拖动 Review Threshold 滑块（默认 35%）
- 拖动 Reject Threshold 滑块（默认 75%）
- 可视化决策区间条：
  ```
  [绿色 PASS 区]‾‾‾[黄色 REVIEW 区]‾‾‾[红色 REJECT 区]
  0%            35%                75%           100%
  ```
- 调整三个权重滑块：关键词权重(0.3)、语义权重(0.5)、历史案例权重(0.2)
- 点"保存配置"→立即生效，无需重启

### 如何验证

- [ ] 新建敏感词策略 → 保存成功 → 返回列表
- [ ] 启用/禁用开关 → 状态切换
- [ ] 调整阈值滑块 → 保存 → 刷新页面 → 值保持
- [ ] 调整权重 → 三个权重之和归一化提示
- [ ] 修改阈值后提交一条审核 → 新阈值立即生效

## 六、技术实验室 — 管线/RAG/Prompt/Skills/MCP

### 页面长什么样

5 个 Tab 切换

### Tab 1: 管线可视化

- 切换不同模态（text/image/audio/video/multi-modal）
- 查看该模态的完整审核流程图（纵向节点 + 连线箭头）
- 点击任意节点展开，查看输入/输出数据
- 对比表展示各模态的 Agent 数量、意见协商、融合等差异

### Tab 2: RAG 调试

- 输入一段文本
- 选择 Top-K（3/5/8/10/15）
- 点"开始检索"
- 查看 6 层检索结果：

```
第 1 层: BM25 关键词检索 → 命中数 + 耗时
第 2 层: Dense 向量检索 (BGE-M3) → 命中数 + 耗时
第 3 层: RRF 融合结果 → 合并去重
第 4 层: CrossEncoder 重排 → 精排分数
第 5 层: AgenticRAG 智能检索 → 改写+路由+自评
第 6 层: GraphRAG 图谱增强 → 关联违规类型
```

### Tab 3: Prompt 工坊

- 浏览所有 Agent 的 System Prompt（含版本号）
- 选择 Prompt 查看完整内容
- **A/B 对比实验**：
  - 输入测试文本
  - 选择 Prompt A 和 Prompt B（或编辑自定义 Prompt）
  - 点"Run Compare"
  - 查看两个 Prompt 的输出对比（决策、置信度、耗时、Token 消耗）

### Tab 4: MCP 工具

- 查看 8 个 MCP 工具的清单
- 每个工具显示：名称、描述、参数定义（必填/可选）、授权 Agent 列表

### Tab 5: Skill 知识库

- 查看 44 个 Skill 的元数据（名称、描述、版本、标签）
- 展开查看完整的 Skill 指令文本
- 查看关联的 MCP 工具

### 如何验证

- [ ] 5 个模态按钮可切换，流程图正确渲染
- [ ] RAG 6 层每层展示命中数量 + 耗时
- [ ] Prompt 列表加载所有 Agent 的 Prompt
- [ ] A/B 对比：两个 Prompt 输出可能不同
- [ ] 8 个 MCP 工具卡片正常渲染
- [ ] 44 个 Skill 展开后显示完整指令内容

## 七、优化监控 — 反馈闭环

### 页面长什么样

- 4 个统计卡片：总处理/正确/误判/漏判
- 缓冲区进度条：错误案例积累进度（满 100 条自动触发优化）
- 手动触发按钮：≥ 3 条即可手动触发
- 标注详情表：每条标注的判定结果
- Prompt 注册表：各 Prompt 的版本历史
- 优化历史时间线

### 你可以做什么

**① 触发优化**：等缓冲区满 100 条自动触发，或点"手动触发"（≥ 3 条即可）

**② 查看标注详情**：点击某条→弹窗看完整详情：
- 原始内容
- AI 原始判定 vs 标注判定
- **规则引擎评审**（关键词命中+白名单+对抗特征）
- **LLM 独立评审**（不同 prompt+temperature 的判定）
- **语义矛盾检测**（violation_type 与 reason 是否自洽）
- **三方投票结果**（2-of-3 裁决）
- 综合裁定语

**③ 查看优化历史**：左侧历史列表，右侧报告详情。报告包含：
- 优化前/后 Prompt 对比
- 错误分布（误判/漏判/类型错误各多少条）
- 优化操作（修改了什么、为什么这样改）
- 预计影响

### 标注详情弹窗的数据来源

标注详情弹窗展示的是 AnnotationAgent 的完整标注流程：

```
① 规则引擎评审:
   - 命中关键词: ["微信", "加微信", "赚钱"]
   - 命中规则: ["keyword:advertisement"]
   - 白名单命中: 否
   - 对抗特征: 否
   - verdict: violation

② LLM 独立审核 (temp=0.7):
   - verdict: violation
   - violation_types: ["advertisement"]
   - confidence: 0.85
   - reason: "含'加微信''赚钱'等引流关键词"

③ 语义矛盾检测:
   - 原始判定: violation_type="none"
   - 原始理由: "内容正常，无违规"
   - 矛盾? 否 (理由本身自洽)

④ 三方投票 (2-of-3):
   - 规则引擎: violation (认为模型错)
   - LLM审核: violation (认为模型错)
   - 矛盾检测: 无矛盾
   → 2票认为模型出错 ≥ 2 → is_error = TRUE
   → error_type = "false_negative" (漏判!)
```

## 八、审核历史 — 记录与日志

### 页面长什么样

2 个 Tab：
- **审核记录**：历史审核列表 + 筛选 + 翻页
- **Pipeline 日志**：审核管线日志列表 + 自动刷新

### 你可以做什么

**① 查看审核记录**
- 列表列：Content ID、类型、决策、风险分、耗时、时间

- 搜索：输入 Content ID 直接跳转详情
- 翻页：支持上一页/下一页/跳转

**② 查看审核详情**：点击"详情"进入详情页：
- **数据概览**：内容类型、决策、风险分、处理时间

- **AI 推理详情**：每个 Agent 的违规类型、置信度、推理链、关键词命中
- **意见协商信息**：模式、意见数、共识度
- **标注结果**：如果有 AnnotationAgent 分析，显示三方投票详情

**③ 查看 Pipeline 日志**：每 5 秒自动刷新
