# 内容风控智能治理平台 — 项目简介

## 项目简介

面向多模态违规内容人工审核效率低、黑灰产对抗手法层出不穷、大模型审核成本高的痛点，基于 LangGraph 构建多 Agent 协同的内容风控智能治理平台，从零实现多模态内容解析、Multi-Agent 协同审核、对抗识别与自进化优化的完整链路，完成从内容接入、智能审核、人工兜底到持续优化的业务闭环，支撑文本、图像、音频、视频全模态违规内容的自动化审核与风险分级。

核心工作如下：

## 多模态审核 Pipeline 与跨模态智能融合

从零搭建覆盖文本、图像、音频、视频四模态的自动化审核链路，针对图文音混合内容设计 Planner 五阶段编排，包括文件解析、并行模态分析、上下文融合、跨模态关联与结果输出。将文档内嵌图片的 ±500 字上下文、OCR 文字与 ASR 转写统一融合进文本审核管线，图片描述按在文档中的精确字符位置插回原文，保持"上文-图片描述-下文"的上下文连贯；同时实现图文矛盾、图文互证、音频关联等跨模态校验。采用固定路线编排替代 LLM 自主调度，调度阶段零推理开销，大模型只专注语义判定。实验结果显示，跨模态互证可使判定置信度提升 15%，多模态文档混合输入审核通过并行编排与并发限流约 2 分钟完成。

## Multi-Agent 协同编排与质量保障机制

基于 LangGraph 构建多 Agent 的有向状态图，通过 4 次条件路由实现按内容类型分发、按风险分级、争议升级、终审裁决的流程控制，配合 MemorySaver 状态持久化支持崩溃恢复。设计辩论、反思、ReAct 深挖、人工兜底四级质量保障，多 Agent 意见不一致时触发辩论面板，置信度不足时触发自我反思修正。普通内容仅走 3-4 个 Agent 快速通过，复杂内容走完整多 Agent 链路深度分析。审核链路设有幂等标记，确保多模态内容经过 Planner 编排后不被下游重复分析，避免同一批图片被处理多轮。

## 三层路由与成本优化

在审核链路入口设置分诊台，基于 ModelRouter 对内容做风险与复杂度的联合估计，将内容分流至三层审核路由：

- **快车道**：针对低风险且结构简单、规则可明确判定的内容，由本地小模型与规则引擎快速判定，全程不调用大模型，毫秒级返回；
- **标准车道**：针对中等风险或命中敏感词、需大模型确认违规类型的内容，走完整的多 Agent 审核链路深度分析；
- **专家车道**：针对超长、超复杂或强信号堆叠的内容，进入大脑仲裁，由多 Agent 联合决策并结合人工兜底。

三层路由使审核成本与内容风险匹配，让低成本模型处理大多数普通内容，大模型仅聚焦真正的难点，在保障准确率的前提下显著降低大模型调用成本。

## 对抗识别与黑灰产检测

构建 AC 自动机敏感词引擎实现毫秒级关键词扫描，针对黑灰产对抗手法实现同音字替换、拆字、Unicode 混淆、火星文等变体归一化识别，并叠加批量生成、关键词变体、格式伪装等黑灰产模式检测与账号风险画像；融合五路召回 RAG 检索为判定提供历史案例依据。针对违规内容藏进大段正常文本的对抗手法，设计双重防漏审机制：一是规则命中段注入，将敏感词、黑灰产模式、对抗规则命中的片段连同上下文单独注入大模型 prompt，要求逐字核查避免注意力稀释；二是长文本分段审核，对超过 3000 字的文本按段落边界自动切块、并行逐块审核，合并时取保守风险分。敏感词检测单次约 1ms，文本端到端审核约 1-2 秒。

## 自动标注与自进化优化闭环

设计 AnnotationAgent 三方投票机制对每条审核结果自动二审，规则明确且与模型一致时快速跳过以节省 LLM 调用；错误案例积累至 100 条自动触发 OptimizationAgent，由 LLM 分析误判与漏判分布后自主执行 Prompt 优化、关键词补充、阈值调整、RAG 案例注入四种优化动作，自动生成新版本。
