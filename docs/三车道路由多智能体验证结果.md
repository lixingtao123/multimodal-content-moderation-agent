# 三车道路由 · 多智能体链路验证结果（R19）

> 依据《全面校验与端到端测试-执行提示词》三车道路由章节执行。
> 全部用例为**真实输入**跑完整 LangGraph workflow，输出 + 日志链路双重核验，无 mock。

## 执行环境
- 快车道小模型：qwen2.5:7b（Ollama 本地部署，GPU），首次加载 ~95s，之后 ~1.5s/短文本
- 大模型：DeepSeek（deepseek-v4-flash）
- RAG：Chroma v2（1024 维，out_safe 396 + seed_data 478）

## 车道 1：low（fast_lane → qwen2.5 本地小模型）

| 用例 | 输入 | 实测决策 | 链路日志证据 | 结论 |
|---|---|---|---|---|
| L1 平凡正常 | "今天天气真好，适合去公园散步" | **PASS** (0.05) | `[triage] low → fast_lane` + `[fast_lane] 小模型判定 PASS conf=0.90（省大模型）` | ✅ |
| L2 无信号隐私 | "陈小姐...她的银行账户余额是多少" | **REVIEW** (0.55) | `triage low → fast_lane` + `小模型判定 REVIEW conf=0.85` | ✅ 拦截 |
| L3 无信号对抗 | "加V信zhuan账，中jiang了" | **REJECT** (0.90) | `triage low → fast_lane` + `小模型判定 REJECT conf=0.90` | ✅ 拦截 |
| L4 短文本 | "嗯嗯好的知道了" | PASS | qwen 平凡判定 | ✅ |

**结论**：low 车道快车道 = qwen 本地小模型判定真实生效。无信号隐私/对抗文本不再被放行（修复前全 PASS）。

## 车道 2：med（text_agent → risk_agent → brain → HITL 降级）

| 用例 | 输入 | 实测决策 | 链路日志证据 | 结论 |
|---|---|---|---|---|
| M1 关键词违规 | "加微信转账汇款，中奖了请联系我们" | **REVIEW/false_info** (0.72) | `triage med 风险信号3个` → `[text_agent] Analyzing` → `[risk_agent] Decision: REVIEW false_info` | ✅ 类型定准 |
| M2 广告多信号 | "点击链接免费领取限量优惠券！扫码关注" | **REVIEW/advertisement** (0.61) | `triage med 风险信号4个` → text_agent → risk_agent 定 advertisement | ✅ |
| M3 辱骂 | "你这个傻逼废物垃圾，去死吧" | **REVIEW/harassment** (0.69) | `triage med 风险信号5个(死,傻逼)` → text_agent → risk_agent harassment | ✅ 类型定准 |

**结论**：med 车道完整走 text_agent（关键词/RAG/LLM）→ risk_agent 聚合 → HITL async 降级 REVIEW。违规类型识别真实准确。

## 车道 3：high/高风险（brain + termination 硬校验）

| 用例 | 输入 | 实测决策 | 链路日志证据 | 结论 |
|---|---|---|---|---|
| H1 高危多信号 | "免费加微信领红包 赌博下注 中奖转账..." | **REJECT/advertisement** (0.78) | `triage med 风险信号10个` → risk_agent REJECT | ✅ |

| H3 制造炸弹 | "制造炸弹 恐怖袭击 杀人教程 犯罪团伙" | **REJECT/violence** (0.75) | `triage 命中硬敏感词: 恐怖袭击` → **`[termination] 硬终止: 高危类型 violence 且 0.75≥0.65`** | ✅ 终止双签触发 |

**结论**：高风险样本终止双签（TerminationChecker）真实触发；硬敏感词识别与违规定类真实准确。

## 本轮发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 全部有害文本被放行 | ModelRouter 低复杂度无信号 → PASS → fast_lane 规则直判 PASS（0 LLM） | 快车道改 qwen2.5 小模型判定，无信号升级大模型 |
| 2 | T1 评测把 REVIEW 当漏判 | 评测口径 REJECT-only | 拦截口径（REJECT+REVIEW）+ strict_reject 参考 |
| 3 | 快车道测试过时 | fast_lane_node 变 async + 依赖 qwen | 更新为 async + mock qwen |
| 4 | 来源加权失效（Mock） | metadata 只读子字段，旧 Mock 顶层 source 丢失 | 兼容顶层 + 子字段两种形态 |
| 5 | 快车道小模型是伪模型 | RuleSmallJudge 规则评分器 | 接入 qwen2.5:7b 本地部署（用户决策），规则作 fallback |

## 遗留（诚实标注）
- H1b 长文本 triage 判 low（复杂度计算未识别长文为 high）→ qwen 保守 REVIEW 兜底，复杂度算法待优化
- 多进程并发时 bge-m3 加载偶发失败（显存竞争）→ Vector search 降级，不影响审核主链路
